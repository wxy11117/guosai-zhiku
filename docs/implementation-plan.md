# CUMCM 赛中诊断 MVP 实施规划

## 本次已实现

- 本地 HTTP 服务与健康检查。
- PDF、DOCX、TXT 论文文本提取。
- ZIP 代码目录静态检查；不会执行用户代码。
- CUMCM 六维 42 项规则检查。
- 规则编号、置信度、原文证据、扣分和修改建议。
- OpenAI Responses API 可选增强评审。
- JSON 与中文 PDF 报告导出。
- 现有工作台真实上传与结果展示。

## 里程碑

### M1：真实诊断闭环（已完成）

以 CUMCM 赛中诊断为唯一真实模板。输入赛题、论文和代码，输出六维评分和证据报告。

### M2：解析质量与规则校准

- 扫描 PDF 检测已经完成；OCR 仍需安装 Tesseract（含中文模型）或接入受控 OCR 服务。
- 引入公式、表格和图片版面解析。
- 邀请指导教师标注 30–50 篇论文，用于调整规则权重。
- 为每条规则增加单元测试和典型正反例。

当前已完成规则版本化配置、页码定位类型、章节/公式/图表统计和教师标注评测脚手架。

验收：文本型 PDF 解析成功率不低于 95%；规则与教师判断的一致率有可复现评测。

### M3：ChatGPT 评审质量评测

- 建立匿名测试集，比较纯规则和规则加模型两种模式。
- 检验引文是否确实来自论文、页码是否可定位、建议是否可执行。
- 记录延迟、输入输出 token 与单篇成本。

验收：模型发现不得包含虚构引文；所有模型结论必须经过本地引文校验。

当前代码已实现 `store: false`、隐私保护安全标识、Token/延迟记录和逐字引文服务端校验。实际质量评测仍需要有效 API Key 与匿名论文集。

### M4：赛后估奖

- 收集带真实奖项标签的往届论文。
- 按赛事、年份、题型和赛区分层校准。
- 输出概率可靠性曲线，而不是未经验证的固定概率。

验收：在独立测试集给出准确率、宏平均 F1 和概率校准误差。

### M5：赛事扩展与机构功能

依次扩展 MCM/ICM、MathorCup，再覆盖官网其余赛事；随后实现批量任务、账号、版本对比和历史记录。

## 安全与隐私

- 默认在本机解析和保存报告。
- 设置 `OPENAI_API_KEY` 后，论文文本摘录会发送到 OpenAI API；界面与部署文档应向用户明确披露。
- 代码压缩包仅检查文件名和目录，不解压到项目目录、不执行。
- 生产部署应增加身份认证、上传限速、任务过期清理和加密存储。
