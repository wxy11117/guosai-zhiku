# 模评云产品需求 v0.1

## 产品定位

模评云为数学建模参赛队、指导老师和培训机构提供赛前论文自动评审。系统不替代建模过程，而是帮助用户发现论文表达、模型论证、格式规范和代码复现中的短板。

## 核心用户

- 参赛队：希望在提交前快速定位冲奖短板。
- 指导老师：希望批量查看学生论文风险项。
- 培训机构：希望沉淀标准化评分规则和报告模板。

## MVP 功能

1. 任务创建：选择竞赛、题号、队伍编号、评审模式并添加论文文件。
2. 材料解析：识别论文结构、摘要、正文、公式、图表、参考文献和附件。
3. 六维评分：假设合理性、建模创新性、结果正确性、表述清晰性、代码可复现性、图文美观性。
4. 风险建议：按高、中、低优先级输出修改建议。
5. 奖项估价：根据综合分和风险项给出奖项概率区间。
6. 报告导出：输出可复盘评分报告。

## 非目标

- 不自动代写论文。
- 不承诺真实比赛获奖结果。
- v0.1 不做在线多人协作。

## 成功标准

- 用户能在 10 分钟内完成一次本地模拟评审。
- 每个维度都有分数和扣分解释。
- 导出报告能被指导老师直接用于复盘沟通。
